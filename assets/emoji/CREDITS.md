# Emoji credits

The chat emoji and the chat/voice/shoutout icons in this folder are unmodified 72×72 PNGs from
**Twemoji** (v15.1.0).

- Source: https://github.com/jdecked/twemoji (originally https://github.com/twitter/twemoji)
- Copyright 2019 Twitter, Inc and other contributors; maintained by the jdecked/twemoji community
- Graphics licence: Creative Commons Attribution 4.0 International (CC BY 4.0),
  https://creativecommons.org/licenses/by/4.0/

Each file is named after the emoji's Unicode code point (e.g. `1f600.png` is U+1F600 😀).
The game shows the attribution "Emoji graphics by Twemoji, CC BY 4.0" in the emoji picker.
